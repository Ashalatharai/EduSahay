# Model evaluation

| Module | Script | Metrics |
|---|---|---|
| CNN classifier | `ml/classifier/evaluate.py` | accuracy, precision, recall, F1, confusion matrix |
| PaddleOCR | `ml/ocr/evaluate.py` | CER, WER |
| LayoutLMv3 | `ml/extraction/evaluate.py` | field precision, recall, F1 |

`python run_all.py` runs whatever is available and writes `reports/summary_<time>.json`. Reports contain
only measured values; anything that could not run says why. Datasets generated by this repo are synthetic,
and every report says so: these numbers show the pipeline works, not how it performs on real documents.
